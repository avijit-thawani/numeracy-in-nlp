# Drop bibliographies here

Put any `.bib` or `.ris` file in this folder and commit it. Every entry is
looked up and added to your survey.

This is the export button in Zotero, Mendeley, EndNote, Google Scholar, and
most journal sites — so getting an existing library in is a drag-and-drop,
not a copy-paste of links one at a time.

Entries are matched by DOI, then arXiv id, then URL, and finally by title if
the entry has no identifier at all. Anything that cannot be matched is
reported in the run log rather than dropped silently.

Leave the files here after importing. They are a record of what came from
where, and re-running never adds anything twice.
